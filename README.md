# NeonDrive

Original open-world 3D driving game project.

## Technology

- C++20
- Vulkan Renderer
- CMake Build System
- GitHub Actions CI/CD

## Targets

- Windows EXE + Installer
- Android APK
- Adaptive graphics scaling

## Platforms

Windows:
- Integrated graphics support
- Dedicated GPU support

Android:
- ARM devices
- Automatic quality adjustment
- Reduced assets for low-end phones

## Build System

All builds are performed through GitHub Actions.
No local compiling required.
